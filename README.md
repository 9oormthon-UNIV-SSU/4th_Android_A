# 4th_Android_A

**구름톤 유니브 숭실대 4기 - Android 스터디 A조**

Jetpack Compose를 중심으로 Android 개발을 학습하고, 실습 및 클론 코딩을 통해 실력을 키우는 스터디입니다.  
스터디는 총 10주차로 구성되며, 매주 워크북 과제 및 코드 리뷰가 진행됩니다.

---

## 📅 스터디 일정

| 주차 | 주요 내용 | 과제 제출 마감 |
|------|-----------|----------------|
| Week 1 | Jetpack Compose 소개 및 기본 컴포넌트 | 4/7 |
| Week 2 | 상태 관리와 Recomposition | 4/14 |
| ... | ... | ... |
| Week 10 | 개인 미니 프로젝트 발표 | 6월 예정 |

> 상세 내용은 각 주차 폴더의 `README.md`를 참고하세요.
